Why it exists

The quantum problem is a signature problem — so we fixed the signatures.

Shor's algorithm breaks the elliptic-curve keys behind Bitcoin and Ethereum. It does not break proof-of-work hashing. Summerpoem draws the obvious conclusion and builds the smallest sound system around it.

Signatures

Post-quantum by construction

Every spend is signed with ML-DSA-44, NIST's primary post-quantum standard. Addresses are SHA3-256 hashes — your public key stays hidden until you spend. For cold storage, opt-in SLH-DSA vault addresses rest on nothing but SHA3 itself.

Mining

Your GPU is the mining rig

SumpHash v1 is memory-hard: a fixed 2 GiB dataset and random reads that make DRAM bandwidth the bottleneck — the resource consumer graphics cards deliver best per dollar. The CUDA miner runs at ~24 MH/s on an RTX 5070 Ti, ~238× a single CPU thread. The dataset never grows, so a 4 GB card stays viable forever.

Launch

Fair, and provably so

No premine, no developer allocation, no early access. The genesis subsidy is paid to the all-zero key — unspendable by anyone, founders included. The founding team mines under the same rules as you.

Mining launch

When the network opens, everyone starts at block one.

Genesis is set for 24 July 2026. The software is built, hardened, and packaged; the genesis hash is published on the roadmap below so you can verify the chain from block one. What launch looks like, committed in advance:

Fair launch. Mining opens for everyone at the same moment. There is no premine and no allocation; the only SUMP that will ever exist is mined, and the genesis reward itself is provably unspendable.

A declared beta period. Following Bitcoin's example, there is no public testnet — the young mainnet is the proving ground, and it is honestly labeled: until permanence is explicitly declared, the chain may be restarted from genesis. Mine accordingly; nothing at stake is hidden from you.

ASIC response, pre-committed. If ASICs for SumpHash ever ship, the algorithm is tweaked at a scheduled hard fork. The credible threat is the deterrent — it kept Monero ASIC-free for years.

How to mine

If you can build a Rust project, you can mine a block today.

Public mining begins at mainnet genesis. Until then, everything is testable on a local regtest chain — the same consensus code mainnet will run.

  1. Build the node

    One binary — node, wallet, and reference miner. Requires the Rust toolchain.

    cargo build --release

  2. Create a chain and a wallet

    Regtest gives you a private network with instant, easy blocks.

    sump genesis
sump wallet new

  3. Mine to your own address

    Block rewards land in your wallet; coinbases mature after a few blocks.

    sump miner mine --blocks 6
sump wallet balance

  4. Or: one command, with a live dashboard

    A single self-contained executable is the node, wallet, and miner. It gossips over ML-KEM-encrypted channels, mines on your GPU (CPU fallback if no CUDA), and serves a local web dashboard.

    sump wallet new
sump node run --mine --gpu --gui

    Open the printed http://127.0.0.1:8787 to watch height, hashrate, and balance update live.

Prefer the prebuilt binary? The Windows download needs no install — unzip it and double-click Start Mining.bat. It's a standalone sump.exe (no dependencies) with launcher scripts. Verify it against the SHA-256 and genesis hash on the release page, or build it yourself from source.
Mainnet hardware: a consumer GPU with at least 4 GB of memory for GPU mining; the CPU miner works on any machine. Running a validating node needs no GPU at all — 64 MiB and any CPU verify the chain.

Upcoming patches

The road to genesis, in order.

Each stage gates the next; mainnet launches after the final stages and a dedicated testing period.

    The network — P2P with post-quantum transport

    Node-to-node gossip, chain sync, and mempool relay over channels encrypted with ML-KEM-768 (FIPS 203) and ChaCha20-Poly1305 — quantum-resistant signatures now travel over quantum-resistant transport. Live two-node sync verified at ≈1,100 blocks/s.

  • v0.3 · shipped · july 2026

    GPU miner kernels

    A CUDA kernel for SumpHash, bit-identical to the CPU reference and verified against it. Measured at ~24 MH/s on an RTX 5070 Ti — ~238× a single CPU thread — proving the memory-bound design runs exactly where it was meant to: on consumer graphics cards.

  • v0.4 · shipped · july 2026

    SLH-DSA vault addresses

    The hash-based output type is live: opt-in vault addresses for cold storage whose security assumes nothing beyond SHA3 itself. Each output records its scheme, and the signature hash commits to it — so a signature can never be replayed across schemes. Verified end-to-end, funding and spending a vault.
